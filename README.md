# Проект «SkillSwap»

> Командный учебный проект курса «Фронтенд-разработчик» от Яндекс Практикума. Приложение разрабатывалось с нуля.

### Задача проекта:

- Разработать SPA-приложение для обмена навыками между пользователями.
- Предусмотреть публикацию предложений, поиск по интересам, заявки и историю обменов.
- Разделить разработку между участниками команды и объединить результаты в общий интерфейс.

## Описание проекта

**SkillSwap** — платформа обмена навыками, где каждый может делиться знаниями и учиться у других без оплаты. Пользователи рассказывают, чему готовы научить и что хотят освоить, а каталог помогает найти подходящие предложения.

## Командная работа

Команда разработала структуру приложения, библиотеку UI-компонентов, страницы и логику основных сценариев:

- Каталог с фильтрами по категориям, подкатегориям, городу, полу и направлению «Могу научить / Хочу научиться».
- Подборки популярных и новых предложений, секцию рекомендаций.
- Страницу навыка с описанием, галереей, информацией об авторе и похожими предложениями.
- Трёхэтапную регистрацию с заполнением профиля, выбором интересов и созданием первого предложения.
- Вход, выход и восстановление состояния авторизации.
- Интерфейсы профиля, избранного и подтверждения предложения обмена.

Код организован по слоям `app`, `pages`, `widgets`, `features`, `entities` и `shared`. Общее состояние хранится в Redux Toolkit.

## Моя роль в команде

- Помогала тимлиду формулировать задачи и разбивать работу на отдельные этапы.
- Проверяла выполненные задачи участников и давала обратную связь.
- Разрабатывала собственные компоненты и участвовала в объединении командного кода.

## Личный вклад

### UI-компоненты и каталог

- Разработала компоненты `Tag`, `Textarea` и календарь с подтверждением и отменой выбора даты.
- Создала блок навыков пользователя `SkillExchangeInfo` и карточку владельца навыка `SkillOwnerCard`.
- Реализовала мегаменю навыков и подключила его к шапке и подвалу.
- Собрала страницу каталога из командных компонентов и добавила секцию рекомендаций.

### Навигация и пользовательские сценарии

- Настроила маршруты приложения и защиту приватных страниц через `PrivateRoute`.
- Доработала переходы между авторизацией, регистрацией и страницей навыка.
- Настроила открытие модальных окон с сохранением фоновой страницы.
- Реализовала постепенный показ рекомендаций при прокрутке с помощью `IntersectionObserver`.
- Связала оформление тегов со справочником категорий навыков.

### Интеграция и исправления

- Исправила отображение превью загруженных изображений и освобождение временных ссылок на файлы.
- Скорректировала отображение выпадающих списков поверх соседних элементов.
- Доработала стили кнопок, галереи и карточек, устранила несогласованность отступов и размеров.
- Подготовила и подключила графические ресурсы из макета.

## Результат:

- Получила опыт разработки приложения в команде: от постановки задач и проверки результатов до объединения отдельных компонентов.
- Научилась работать с общими интерфейсами компонентов и учитывать зависимости между задачами участников.
- Закрепила разработку переиспользуемых React-компонентов с типизированными props и управляемым состоянием.
- Освоила защищённые маршруты, возврат пользователя после авторизации и навигацию с модальными окнами.
- Получила практику работы с `IntersectionObserver`, очисткой таймеров и освобождением ресурсов изображений.
- Научилась находить и исправлять несогласованность стилей и поведения при интеграции командного кода.

### Текущая версия

Приложение использует демонстрационные JSON-данные. Регистрация и авторизация работают на стороне браузера, новые пользователи и навыки сохраняются в `localStorage`.

Сохранение изменений профиля, подключение страницы избранного к данным и полноценная работа с заявками и историей обменов пока не завершены. Отдельная страница создания навыка содержит заглушку. Создание первого предложения доступно при регистрации.


## Запуск

1. Установите зависимости:

```bash
npm ci
```

2. Запустите приложение:

```bash
npm run dev
```

Тестовое окружение настроено, но файлы с тестовыми сценариями в текущей версии отсутствуют.
